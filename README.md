# The-super-editions-mod
A mod that enhances the emphasis on editions in balatro! Adds something for the 4 editions in balatro in every aspect of the game!

In order to install this mod, ensure you have the newest steammodded version. Go to the assets page of this project and download the zip file. Put this zip file in your balatro mods folder without extracting it prior. Extract the zip within a folder of your mods folder. Preferrably name it "The super editions mod".
